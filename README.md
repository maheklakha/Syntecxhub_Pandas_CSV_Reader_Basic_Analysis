# Pandas CSV Reader & Basic Analysis

## Dataset
Employee Dataset

## Objective
Read the Employee dataset using Pandas and perform basic data analysis.

## Steps Performed
- Loaded the CSV dataset into a DataFrame.
- Displayed the first and last records using head() and tail().
- Checked data types using info() and dtypes.
- Calculated summary statistics using describe().
- Filtered rows based on Age > 30.
- Selected required columns.
- Sliced subsets using iloc.
- Saved the filtered data as filtered_employee.csv.
